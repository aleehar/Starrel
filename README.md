# Starrel

Starrel is a responsive **art prints e-commerce website** designed to provide a clean and user-friendly online shopping experience.

## Features

* User Login and Sign Up pages
* Product categories
* Best Sellers section
* Shopping cart
* Payment page
* Thank You page
* Responsive and visually appealing design
* Interactive product and cart functionality

## Technologies Used

* HTML
* CSS
* JavaScript

## Project Purpose

Starrel was developed as a web development project to practise front-end development, user interface design, and interactive website functionality.
